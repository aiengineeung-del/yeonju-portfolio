# yeonju-portfolio
Yeonju Kim's portfolio: validating time- and resource-waste problems with data and AI

시간과 자원이 새는 문제를 찾아, 데이터와 AI로 검증하는 과정을 담은 포트폴리오 사이트입니다.

사이트 보기: https://aiengineeung-del.github.io/yeonju-portfolio/

# 담긴 내용

- 세 가지 문제와 검증 계획: 외식업 운영 자동화, 배터리 자원 순환, 미용 서비스 연결
- 도전·성취·혁신: 팀 프로젝트 두 건(알약 이미지 인식, RFP 요약 RAG) 결과
- 아이디어를 검증하는 방식과 2년 실행 계획

# 구성

- `index.html` 한 개로 이루어진 정적 웹페이지입니다. (서버나 설치가 필요 없습니다.)
- HTML, CSS, JavaScript만 사용했고, 글꼴은 Google Fonts를 불러옵니다.
- 밝은 화면과 어두운 화면, 휴대폰 화면을 지원합니다.
