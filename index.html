저는 새로운 기술 자체보다, 기술로 사람의 시간과 자원을 아끼고 사업이 지속될 수 있는 구조를 만드는 데 관심이 있습니다. 2년 동안 직접 실험해 볼 문제를 세 가지로 정리했습니다.

주방의 시간과 식재료가 엑셀 밖에서 새고 있습니다

직원 스케줄, 인건비 계산, 식재료 사용량과 재고 관리가 여전히 엑셀과 수작업에 의존합니다.

제가 아는 현장

양식 주방에서 해외 수셰프와 국내 법인의 전 업무·영양사 업무를 맡았습니다. 결원이 생기면 작업 순서와 동선을 조정했고, 원가와 판매가를 계산해 의견을 조율했습니다. 헤드셰프가 어려워하던 엑셀·계산 업무에 필요한 정보도 정리해 도왔습니다.

첫 실험
  • 근무 가능 시간·숙련도·인건비를 반영한 로테이션 일정
  • 식재료 사용량과 재고를 연동한 발주량 계산
  • 바코드·이미지 인식을 활용한 입출고 확인
확인할 것

버려지는 식재료(로스)가 줄었는지, 일정과 발주를 짜는 데 드는 시간이 줄었는지 기록으로 비교합니다.

활용할 기술

Python 기반 일정·발주 계산, 이미지 인식(알약 118종을 구분하는 객체탐지 프로젝트 경험을 확장)

  • 1지망 기술·탐구
  • 생활 속의 문제
  • 지역과 공공의 과제

언제 바꾸고 언제 버려야 할지, 배터리는 알려 주지 않습니다

배터리의 잔여 용량을 쉽게 확인하기 어려워 교체 시점이나 분리배출 시점을 판단하기 어렵습니다.

출발점

제 현장 경험이 닿지 않는 영역입니다. 그래서 기술부터 정하지 않고, 사람들이 배터리를 실제로 언제 바꾸고 어떻게 버리는지 인터뷰와 관찰로 먼저 확인하겠습니다. 예상과 다른 결과를 받아들이고 실험 조건부터 점검하는 방식으로 일해 왔습니다.

첫 실험
  • 배터리 상태를 측정하는 방법 조사와 간단한 시제품
  • 측정 결과에 따라 재사용 또는 분리배출을 안내하는 서비스 흐름 구성
확인할 것

안내를 받은 사람이 교체와 분리배출 판단을 실제로 바꾸는지, 불필요한 소비와 자원 낭비가 줄어드는지 확인합니다.

활용할 기술

측정 데이터 분석, 안내 기능을 웹·앱 서비스로 구현하는 역량(Python과 AI 기술을 더 익혀 키우겠습니다)

  • 2지망 창업·비즈니스
  • 새로운 가치 만들기

미용실과 네일샵을 따로 예약하며 시간이 버려집니다

고객의 위치와 이동 동선에 따라 미용실과 네일샵을 연결하는 예약 서비스를 구상하고 있습니다.

제가 아는 현장

네일 매장을 약 5년간 운영했습니다. 예약제로 바꿔 일정을 예측 가능하게 만들었고, 고객의 방문과 이용 패턴을 관찰했습니다. 필요해서 직접 찾아오는 단골이 분명히 보였고, 매장 평수와 공간감에 맞춰 고객과 직원의 동선을 배치했습니다.

첫 실험
  • 고객에게는 통합 예약과 쿠폰으로 이동·대기 시간을 줄여 줍니다.
  • 매장에는 서로의 고객층을 연결할 기회를 줍니다.
  • 소수의 매장과 함께 작은 규모로 시작해 반응을 확인합니다.
확인할 것

고객이 묶음 예약을 실제로 이용하는지, 두 매장 사이의 이동·대기 시간이 줄었는지, 매장이 서로의 고객 연결에서 이익을 얻는지 봅니다.

활용할 기술

위치·동선 기반 예약 기능을 갖춘 웹·앱 서비스 시제품

세 문제의 공통점은 같습니다. 사람의 시간과 자원이 구조 때문에 새고 있고, 그 구조를 바꾸면 사업이 오래 갈 수 있다는 점입니다.

도전, 성취, 혁신

지금까지의 증명

도전

오래 해 온 현장의 방식을 내려놓고, 비전공자로서 AI를 처음부터 배우기 시작했습니다.

  • 팀 프로젝트 두 건에서 부족한 Python과 RAG 기초를 따로 공부하며 따라갔습니다.

성취

두 번의 팀 프로젝트에서 결과를 냈습니다.

  • 알약 118종 인식: 클래스 번호 매핑 오류를 찾아 고친 뒤 프로젝트 중 최고 캐글 점수를 기록했습니다.
  • RFP 요약 RAG: 같은 조건의 비교로 결론을 얻고, 일정 관리를 맡았습니다.

혁신

일하는 구조 자체를 바꿔 본 경험이 있습니다.

  • 워킹 고객 일부를 놓치는 손해를 알면서도 예약제로 바꿨습니다.
  • 확보한 시간에 보험 설계 업무를 배치해 한 사업의 시간을 다른 소득 활동과 연결했습니다.

아이디어는 이렇게 검증합니다

검증 방식

  1. 관찰현장에서 시간과 자원이 새는 지점을 찾습니다.
  2. 가설"이렇게 바꾸면 줄어든다"를 한 문장으로 적습니다.
  3. 작은 시제품가장 작은 형태로 만들어 씁니다.
  4. 측정같은 기준과 같은 조건으로 전후를 비교합니다.
  5. 고치기결과가 예상과 달라도 받아들이고 다시 합니다.

예상이 틀렸을 때

알약 인식에서 세 모델 모두 기본 설정이 튜닝한 설정보다 점수가 높았고, 이미지를 변형해 여러 번 예측하는 기법은 오히려 점수를 떨어뜨렸습니다. 기법을 더하는 대신 데이터 연결 상태를 점검했고, 문제는 번호 매핑이었습니다.

기준선부터 세울 때

RFP RAG에서 직접 구축한 방식이 외부 API 방식보다 나은지 가려내려고, 먼저 API 방식으로 기준 점수를 만들었습니다. 평가 데이터와 코드 버전이 같을 때만 점수를 비교하는 규칙으로 서로 다른 조건의 점수를 섞지 않았습니다.

2년 동안 이렇게 키우겠습니다

2년 계획

  1. 생활 속의 문제배터리 문제를 사람들의 실제 사용 방식에서 정의합니다

    인터뷰와 관찰로 문제의 크기와 원인을 확인합니다.

  2. 지역과 공공의 과제자원 순환의 관점으로 범위를 넓힙니다

    분리배출과 재사용이 지역과 공공의 과제와 어떻게 이어지는지 살핍니다.

  3. 인간과 사회에 대한 질문사람의 시간과 에너지가 어디에 쓰이는지 묻습니다

    세 문제가 사용자와 일하는 사람의 시간과 에너지에 주는 의미를 점검합니다.

  4. 분야별 현장의 문제외식업 현장에서 운영 자동화를 실험합니다

    로테이션 일정과 발주 계산의 효과를 로스와 작업 시간으로 비교합니다.

  5. 새로운 가치 만들기미용 서비스 연결로 창업 아이디어를 검증합니다

    최소한의 기능으로 만든 시제품으로 이용 의향과 매장 반응을 확인합니다.

  6. 나의 커리어 설계검증 결과를 포트폴리오로 정리하고 진로를 정합니다

    가능성이 확인된 문제를 현장에서 실제로 운영하며 마무리합니다.

과정의 모듈 구성과 순서에 맞춘 제 계획이며, 멘토와 동료의 의견에 따라 조정하겠습니다.

기술로 사람의 시간과 자원을 아끼고, 사업이 지속되는 구조를 만들겠습니다.

AIGEN에서 다양한 배경의 동료들과 실제 문제를 탐색하고, 사용자 관점에서 해결책을 정의하며, 데이터와 AI로 아이디어를 검증하는 경험을 쌓고 싶습니다. Python과 AI 기술을 더 깊이 익혀 필요한 기능을 웹이나 앱 서비스로 구현하는 역량을 키우고, 실험과 피드백을 반복하며 아이디어를 실제로 쓸 수 있는 서비스로 발전시키겠습니다.
